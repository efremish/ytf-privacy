# Инструкция для Матвея — ytf на WINDOWS
# (автозаливка type beat на YouTube)

## Что это такое

**ytf** — программа, которая автоматизирует выпуск type beat видео.
Один запуск = одно видео на канале. Она сама:

1. Проверяет, какие даты на канале свободны (через YouTube API)
2. Берёт свободный слот — сегодня, если свободно, иначе завтра
3. Берёт случайный трек и фон из папки канала (без повторов)
4. Собирает заголовок, описание и теги из шаблонов — сама выцепляет
   имя бита, BPM и тональность из имени mp3:
   `BABY 104BPM D MIN.mp3` → «BABY», «104 BPM», «D MIN»
5. Рендерит видео 1920×1080 @ 30fps локально через ffmpeg
   (фон + трек, «выход из темноты» в начале).
   Кадр: центр-квадрат из картинки + чёрные полосы по бокам.
6. Заливает на YouTube с отложенной публикацией (по умолчанию 22:00)
7. **Сам проверяет, что YouTube принял файл** (ждёт статус processed;
   если файл не принят — честно пишет ошибку, а не «успех»)
8. Ставит свою обложку, если YouTube выбрал чёрный кадр
9. Чистит временные файлы и пишет журнал history.json

Видео появляется на канале само в назначенное время. Компьютер нужен
только на время работы программы (~2–5 минут на видео).

Терминал НЕ нужен: всё делается через меню, двойным кликом.

## Установка — 3 минуты

1. Распакуй архив ЦЕЛИКОМ в папку БЕЗ русских букв, например:
   ```
   C:\ytf\
   ```
   (правый клик по zip → «Извлечь всё…» → путь C:\ytf)
   Внутри: ytf.exe, settings.json, People, tools, ytf-menu.bat и т.д.

2. Открой папку C:\ytf и запусти двойным кликом **ytf-menu.bat** —
   откроется меню программы. Всё, установка закончена.

Если Windows ругается «Защитник заблокировал приложение» — нажми
«Подробнее» → «Выполнить в любом случае» (файл без цифровой подписи,
это нормально, код открыт и лежит в GitHub).

Первым делом в меню выбери **1** (проверка). Должно показать:
ffmpeg OK, настройки OK. ffmpeg уже в архиве — ставить ничего не надо.

## Подготовка Google — ОДИН раз на все каналы (10 минут)

Это единственный шаг, где нужен браузер, но делается один раз.

1. Зайди на https://console.cloud.google.com под СВОИМ Google-аккаунтом,
   создай проект (любое имя, например ytf-pipeline).

2. APIs & Services → Library → включи две API:
   - YouTube Data API v3 (кнопка Enable)
   - YouTube Analytics API (кнопка Enable)

3. APIs & Services → OAuth consent screen (Google Auth Platform):
   - User type: External
   - Branding: App name — любое; User support email — твоя почта
   - Application home page и Application privacy policy — ОБЯЗАТЕЛЬНО
     (без них кнопка Publish будет серой). Если нет своего сайта:
       а) создай ПУБЛИЧНЫЙ репозиторий на GitHub (например ytf-site)
       б) залей туда два файла из папки site\ архива:
          index.html и privacy.html
       в) Settings → Pages → Branch: main / (root) → Save
       г) через минуту сайт живой: https://твойлогин.github.io/ytf-site/
     Впишы эти две ссылки в Branding, а в Authorized domains добавь:
     твойлогин.github.io
   - Developer contact information — твоя почта
   - Логотип НЕ загружай (из-за него запросит верификацию бренда)

4. Вкладка Audience → кнопка **Publish app** → подтвердить.
   Статус станет «In production». БЕЗ ЭТОГО токены живут 7 дней и
   протухают — не пропускай.

5. Credentials → Create credentials → OAuth client ID:
   - Application type: **Desktop app**
   - Create → кнопка **Download JSON**

6. Переименуй скачанный файл в client_secret.json и положи в C:\ytf\
   (рядом с ytf.exe).

## Подготовка папки канала — 5 минут

Готовый шаблон: People\my\channel-template\. Скопируй папку с новым
именем для каждого канала и наполни:

```
People\my\my-channel\
├── music\        треки mp3/wav (ИМЯ ФАЙЛА = источник метаданных!)
├── pictures\     фон: картинки jpg/png ИЛИ mp4-видео для зацикливания
├── names\        заголовки, по одному в строке (NAMETRACK заменится)
├── description\  описание (NAME_XXX → имя, BPM_XXX → bpm, KEY_XXX → тональность)
├── tags_for_video\        теги видео через запятую
└── tags_for_description\  теги в конец описания через запятую
```

Пример имени трека: backrooms_104bpm_Cminor_bounce kid.mp3
→ бит «backrooms», 104 BPM, C MIN.
Понимаются форматы: D MIN, Gmin, Cminor, A#minor, G Maj.

После наполнения: меню **2** (показать каналы). Канал должен быть
с пометкой [+] (восклицательный знак [!] = не хватает файлов).

## Подключение аккаунта канала — 2 минуты на канал

ВАЖНО: YouTube-аккаунт канала должен быть залогинен в Nstbrowser
(профиль канала), либо в обычном браузере под этим аккаунтом.

1. Запусти **ytf-menu.bat** → выбери **4** (Подключить аккаунт).
2. Меню покажет список каналов. Впиши ИМЯ ПАПКИ канала
   (например my-channel) и Enter.
3. Впиши название канала на YouTube (можно просто Enter).
4. Программа напечатает ссылку Google и СРАЗУ скопирует её
   в буфер обмена (сообщение «ссылка скопирована в буфер обмена»).
5. Вставь ссылку (Ctrl+V) в адресную строку ОКНА ПРОФИЛЯ КАНАЛА
   в Nstbrowser и открой.
   Если на одной почте НЕСКОЛЬКО YouTube-каналов — Google покажет
   список каналов: выбери ИМЕННО нужный (канал, а не основную почту).
6. Нажми «Продолжить» / «Allow».
   Если Google пугает «приложение не проверено»: «Дополнительные
   настройки» → «Перейти на страницу (небезопасно)» → «Продолжить».
   Это нормально — приложение твоё личное.
   ВАЖНО (Google 2026): на экране согласия отметь галочки разрешений
   — **Select all**, иначе кнопка Continue выдаст токен БЕЗ прав
   (программа сразу напечатает предупреждение «право загрузки НЕ
   выдано» — тогда повтори подключение, отметив галочки).
7. Браузер покажет «страница недоступна» — ЭТО НОРМАЛЬНО, так задумано.
   В адресной строке будет адрес вида:
   http://localhost/?code=4/0AX...&scope=...
8. Скопируй ВЕСЬ адрес из адресной строки (Ctrl+L, затем Ctrl+C),
   вернись в меню, вставь (Ctrl+V), Enter.
9. Программа сама запишет токен и сразу проверит канал:
   ```
   [OK] my-channel -> Название канала на YouTube (videoId: UC...)
   ```

Повторить для каждого канала. Токен вечный (пока не отозван вручную),
хранится в tokens.json только на твоём компьютере.

## Публикация

Запусти **ytf-menu.bat** → выбери **5** (Опубликовать видео) →
впиши имя папки канала → Enter.

Все каналы сразу: пункт **6**.

Что увидишь: слот публикации → рендер → загрузка →
`[OK] ... принято YouTube` → ссылка на видео.
Всё попадает в history.json.

Видео само станет публичным в назначенное время (по умолчанию 22:00,
зона Asia/Omsk — меняется в settings.json блокнотом).

Пункт **7** — тестовый рендер БЕЗ загрузки: проверит, что с папкой
канала всё ок, ничего на YouTube не отправляя.

## Настройки (settings.json — открывать Блокнотом)

| Поле                        | Что значит                                    |
|-----------------------------|-----------------------------------------------|
| publish.hour / minute       | время публикации (22:00)                      |
| publish.timezone            | зона (Asia/Omsk — поменяй на свою)            |
| publish.horizon_days        | на сколько дней вперёд планировать            |
| render.fade_from_black_secs | «выход из темноты» в секундах (0 = выкл)      |
| render.seamless_loop        | зацикливание видеофона палиндромом            |

Режимы фона (_config.json канала, обычно менять не надо):
- Random — случайная картинка из pictures\
- Loop — случайное видео из pictures\, зацикленное палиндромом
  (конец ровно на конце трека, без зумов и тряски)
- Single — конкретный трек+фон под релиз

## Шортсы (Shorts) — в меню пункт 8

Готовые вертикальные видео заливаются БЕЗ рендера — просто сложи
файлы .mp4 в папку:

```
Shorts\имя-канала\
├── clip1.mp4      заголовок на YouTube = имя файла
├── clip2.mp4
└── _config.json   необязательно: описание, теги, категория
```

Пункт меню **8** → введи имя папки (или Enter — залить всё).
Залитые файлы переезжают в `Shorts\имя-канала\_uploaded\`.
В веб-панели появилась вкладка **«Шортсы»** — там видно очередь
и кнопка «Залить». Токены используются те же, что и для обычных
каналов (имя папки в Tokens.json должно совпадать).

## Логи — если что-то не работает

Каждый запуск пишет лог в папку `logs\` (рядом с программой):

```
logs\ytf-2026-10-12.log
```

Там видно: подключение каналов, проверку токенов, ход публикаций
и ВСЕ ошибки (включая ответы Google). Если что-то не выложилось —
просто скинь файл за сегодня. Старые логи старше 14 дней удаляются
сами.

## Возможные проблемы

| Симптом | Что делать |
|---|---|
| «Защитник заблокировал файл» | «Подробнее» → «Выполнить в любом случае» (нет цифровой подписи, это нормально) |
| Меню закрылось с ошибкой | запусти ytf-menu.bat заново; посмотри, что написано перед закрытием |
| invalid_grant в tokens | токен протух (приложение было в Testing) — повтори auth (пункт 4). Если повторяется — проверь, что нажал Publish app в Google |
| Кнопка Publish app серая | не заполнены home page + privacy policy в Branding (см. раздел Google) |
| «суточный лимит загрузок» (uploadLimitExceeded) | YouTube ограничивает новые каналы ~10 заливок в день. Просто повтори завтра |
| «не обработано YouTube за N мин» | файл не принят — запусти публикацию ещё раз. Если повторится — напиши мне |
| Google просит «Verify it's you» в Studio | обычная проверка безопасности — пройти. На заливки через API не влияет |
| Канал не находится в auth | имя папки должно совпадать точь-в-точь; проверь через пункт 2 меню |
| 403 «не хватает прав ставить обложки» | аккаунт не верифицирован по телефону — это требование Google: подтверди номер на https://www.youtube.com/verify (один раз). Остальное работает и без верификации |
| Плейсхолдеры типа KEY_XXX в описании | не распозналась тональность — переименуй трек: ИМЯ 120BPM A MIN.mp3 |

**Лимиты YouTube (важно для масштаба):** ~10 заливок в сутки на новом
канале; квота API — 100 видео/сутки на проект Google. 10 каналов ×
1 видео в день = норма для одного проекта.

## Безопасность

- client_secret.json и tokens.json — СЕКРЕТНЫЕ файлы, никому не пересылай
  (у кого токен — тот может заливать на канал)
- Отозвать доступ: https://myaccount.google.com/permissions
- Программа общается только с Google (YouTube API); ffmpeg работает локально

## Шпаргалка: с нуля до первого видео

```
1. Распаковать архив в C:\ytf
2. Запустить ytf-menu.bat → пункт 1 (проверка)
3. Google-проект (раздел выше) → client_secret.json в C:\ytf\
4. Скопировать People\my\channel-template → наполнить треками/фонами
5. ytf-menu.bat → пункт 4 (Подключить аккаунт)
      ссылка в буфере → в профиль канала Nstbrowser → «Продолжить»
      → скопировать адрес из браузера → вставить в меню → Enter
6. ytf-menu.bat → пункт 5 (Опубликовать)
```

Готово — видео выйдет само в 22:00.
