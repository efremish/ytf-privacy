Privacy Policy

Last updated: September 2026

This Privacy Policy describes how the ytf pipeline desktop tool ("the tool") handles information when it is authorized to access a Google account through the Google OAuth consent screen.

Information the tool accesses

  • YouTube account data — only to upload videos, set thumbnails, and read channel/analytics data for channels belonging to the authorizing account.
  • Local media files — audio and image files selected by the user, processed on the user's own computer.

How information is used

  • To render and publish videos to the YouTube channels of the account that authorized the tool.
  • To schedule publication times and check upload status.

Storage

  • OAuth tokens are stored locally, on the user's own machine, in a local file. They are never transmitted to any third-party server.
  • Rendered video files are deleted from the local machine immediately after a successful upload.
  • The tool does not use any third-party analytics, advertising, or tracking services.

Sharing

No personal data is sold, rented, or shared with third parties. The only external service contacted is Google's YouTube Data API v3, and only to perform the actions described above on behalf of the authorizing account.

Data deletion

The user can revoke the tool's access at any time through their Google Account settings at myaccount.google.com/permissions, which immediately invalidates the stored tokens.

Compliance with Google API Services User Data Policy

The tool's use of data obtained through Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions about this policy can be sent to the developer contact address listed on the OAuth consent screen configuration.
