ytf pipeline

ytf pipeline is a personal desktop tool that renders audio tracks into video files and uploads them to YouTube channels owned and operated by the same person who runs the tool.

What it does

  • Renders local audio files into 1080p videos locally, on the user's own machine.
  • Uploads those videos to the user's own YouTube channels using the YouTube Data API v3.
  • Sets the video thumbnail and the scheduled publication time.
  • Deletes the local video file after a successful upload.

What data it accesses

The tool requests access to your Google account only for the following purposes: uploading videos, managing thumbnails, and reading basic channel and analytics data belonging to the account that authorizes it. It is used exclusively by its owner and is not offered to the public.
